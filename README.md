## Структура проекта
* **src/main/java** — содержит исходный код программы на языке Java, включая пакеты, классы логики и основной класс точки входа для инициализации мода.
* **src/main/resources** — содержит статические ресурсы проекта, конфигурационные файлы (такие как `fabric.mod.json`), текстуры, модели и языковые файлы перевода.

## Игровой объект
* **Идентификатор:** `template-mod:heavy_drill`
* **Назначение:** Высокотехнологичный бур для быстрого и эффективного разрушения блоков в радиусе 3х3.

## Свойства объекта
1. `stacksTo(1)` - Максимальное количество предмета в одной ячейке инвентаря.
  * *Назначение:* Его невозможно складывать в стопки, ведь «Твой бур — это бур, который пронзит небеса!», и он должен занимать почетное место в инвентаре в единственном экземпляре.   
2. `durability(10000)` - Прочность инструмента. 
  * *Назначение:* Столь огромное значение прочности обусловлено тем, что этот бур работает на неиссякаемой Спиральной Энергии и силе духа владельца.
3. `fireResistant()` - Устойчивость к горению в огне и лаве.
  * *Назначение:* Этот бур не может сгореть в огне или лаве т.к. его внутренне пламя горит гораздо ярче.
